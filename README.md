# pad-rag

`pad-rag` — учебный репозиторий по курсу **Programarea Aplicațiilor Distribuite (PAD)**.

## Цель проекта

Подготовить и защитить лабораторные работы по теме Retrieval-Augmented Generation (RAG), с акцентом на воспроизводимые эксперименты и инженерную дисциплину.

## Дорожная карта (3 лабораторные)

1. **ЛР1**: построение и экспериментальная оценка RAG-системы.
2. **ЛР2**: разработка backend-приложения на основе результатов ЛР1.
3. **ЛР3**: контейнеризация и оркестрация приложения из ЛР2.

## Текущий статус

Сейчас подготовлен только фундамент репозитория: структура, документация, правила работы, базовый Python scaffold и CI для lint/test.

**RAG-конвейер пока не реализован.**

## Предложенный scope для ЛР1 (пока не утверждён)

- Домен: ограниченное подмножество документации Flutter.
- Язык реализации: Python.
- Кандидаты: Sentence Transformers + FAISS (как гипотеза, не финальное решение).

## Структура репозитория

- `docs/` — общий контекст проекта, план, статусы, протокол оценки.
- `lab1/` — код и артефакты ЛР1.
- `.github/workflows/` — CI workflow для быстрых проверок.
- `CLAUDE.md`, `GEMINI.md`, `AGENTS.md`, `.github/copilot-instructions.md` — краткие инструкции для AI-ассистентов.

## Установка и команды проверки

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e "./lab1[dev]"

pytest lab1/tests -q
ruff check lab1/src lab1/tests
python -m pad_rag.cli --version
python -m pad_rag.cli status
```

## Важно

Этот этап не включает полную реализацию RAG, микросервисы или Kubernetes. На текущем шаге создаётся только аккуратная, проверяемая база для дальнейшей разработки.
